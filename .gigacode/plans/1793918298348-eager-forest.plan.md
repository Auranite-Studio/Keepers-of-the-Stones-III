# Plan: Fire Stone Curios Activation

## Summary
When **Fire Stone** is equipped in Curios **Accessory** slot → player receives full Fire Armor (with Curse of Binding) + Fire Sword. When stone is unequipped → all items removed.

---

## Step 1: Add Curios API Dependency

**File:** `build.gradle`

Add CurseMaven repository and Curios dependency:
```groovy
repositories {
    maven { url "https://www.cursemaven.com"
        content { includeGroup "top.theillusivec4.curios" }
    }
}
dependencies {
    implementation "curse.maven:curios-forge-309945:<file_id>"
}
```
> Replace `<file_id>` with latest Curios 1.21.1 file ID from https://www.curseforge.com/minecraft/mc-mods/curios/files

**File:** `neoforge.mods.toml`

Add soft dependency:
```toml
[[dependencies.kots]]
modId="curios"
type="optional"
versionRange="[10.0.5,)"
ordering="NONE"
side="BOTH"
```

---

## Step 2: Create Event Handler

**NEW File:** `src/main/java/.../event/FireStoneCuriosHandler.java`

Key logic:
- `@SubscribeEvent` on `CuriosEvent.Equip` — if stack is Fire Stone → `grantFireSet(ServerPlayer)`
- `@SubscribeEvent` on `CuriosEvent.Unequip` — if stack was Fire Stone → `removeFireSet(ServerPlayer)`
- `@SubscribeEvent` on `PlayerTickEvent.Post` — if no Fire Stone in curios → remove Fire Sword from inventory
- `grantFireSet()`: equip 4 armor pieces with `Curse of Binding`, add Fire Sword to inventory
- `removeFireSet()`: clear all Fire Armor from equipment slots, remove Fire Sword from inventory

---

## Step 3: Register Handler

**File:** `KeepersOfTheStonesIIIMod.java`

Register handler in constructor:
```java
import ...event.FireStoneCuriosHandler;
// ...
NeoForge.EVENT_BUS.register(new FireStoneCuriosHandler());
```

## Verification

1. `.\gradlew build` — compile with Curios API
2. `.\gradlew runClient` — run client
3. In-game:
   - Get Fire Stone (creative)
   - Open Curios (key: C), place stone in Accessory slot
   - Verify: Fire Armor equipped with Curse of Binding (visible in tooltip, can't be removed)
   - Verify: Fire Sword in inventory
